# 囲碁スピード整地バトル 仕様書（ドラフト）

囲碁の整地を素早く完了させた方が勝ち、というゲームの HTML アプリケーション。

- 状態: ドラフト（未確定事項は「**未確定**」と記載）
- UI 言語: 日本語のみ
- 公開先: GitHub Pages（静的サイト）
- プレイヤー向けのルール説明は [rulebook.md](rulebook.md) を参照

---

## 1. 用語

| 用語 | 意味 |
| --- | --- |
| 地 | ある色の石（と盤端）だけで囲まれた空点の集まり |
| 区間 | 整地後の地を構成する、石で区切られた個々の空点の連結領域 |
| 死に石 | 終局時点で取られる運命にある石。整地中にアゲハマとして取り上げる |
| アゲハマ | 対局中に取った石と死に石。盤外のトレイに置き、相手の地に埋める |
| 目数（スコア） | 地の空点数 − 相手に取られた自分の石（アゲハマ）の数（日本ルール） |
| 担当 | 整地する地。囲碁の慣例どおり **相手の地を整地する** |

## 2. 整地ルール

### 2.1 完成形の条件

ある色の地について、次をすべて満たすとき「整地完了」とする。

1. 各区間は、その色の石と盤端だけで囲まれている。
2. 各区間は、辺で接する空点どうしの連結領域として独立している。
   - 区間どうしは石で明確に区切る。
   - ただし、区間どうしが **頂点（斜め方向）だけで接する** のは OK。
3. 各区間は「10 の倍数の区間」か「余りの区間」のいずれかである。
4. 「余りの区間」は、その色の地全体で **最大 1 つ**。
   - 例: 35 目 → 10+20+5、10+10+10+5、30+5 など
5. 盤上に死に石が残っておらず、その色の地に埋めるアゲハマもすべて埋め終わっている。
   - アゲハマが地の空点より多い場合は、空点をすべて埋めた状態を完成形とする。地の空点は 0 で、埋めきれなかったアゲハマはトレイに残る。このとき目数はマイナスになる（§2.6）。
6. ダメはすべて埋まっている（自動で埋める。§5 参照）。

頂点共有の例（左上の 3x2 と右下の 4x5 は頂点だけで接しており、その頂点に石がないが OK）:

```
...xxxx
...xxxx
xxx....
xxx....
xxx....
xxx....
xxx....
```

### 2.1.1 整地ルールの設定

ゲーム設定の「整地ルール」で、区間の形の条件を追加・緩和できる（完了判定に使う。CPU とおまかせも従う）。

- **1 列の区間**（初期値: 制限なし）
  - 10 目以上は禁止: 10 目以上の区間を 1 列（幅か高さが 1）にできない（1x10、1x20 など不可）。
  - 5 目以上は禁止: 加えて、5〜9 目の余りの区間も 2 列以上にする（2x2+1、2x3、2x3+1、2x4、3x3、2x4+1）。
  - しっぽ付きの余りは、しっぽを除いた矩形が 1 列なら 1 列とみなす（1x4+1 など）。
- **5 × 奇数**（初期値: 認めない）
  - 認める: 一辺が 5 で他方が 3 以上の奇数の矩形（3x5 = 15、5x5 = 25、5x7 = 35 など）も、10 の倍数の区間と同じく数えやすい区間として認める。余りの区間は引き続き全体で 1 つまで。
- CPU（vs CPU の相手とおまかせ）は、設定によらず、まず 5 目以上の区間を 1 列にしない形で探す（10 目は 2x5・3x4−2 など、余り 5〜9 目は 2 列以上）。見つからないときだけ、設定で許される範囲で 1 列の形も使う。
- 自動で作る終局図は、設定した整地ルールで CPU が整地できるものだけを採用する。

### 2.3 余りの区間

目数は 1〜9 目。他の区間と独立して配置する（§2.1 の 2）。許可する形は次のとおり。

- 矩形（1xN を含む）
- 奇数目のときのみ、矩形の辺に接する位置に「しっぽ」1 マスを付けた形
  - 例: 5 = 2x2+1、7 = 2x3+1、9 = 2x4+1

### 2.4 石の操作

- 盤上の石は、自分の色・相手の色を問わず動かせる。新しい石は使わない。
- **アゲハマトレイ**
  - 黒のアゲハマ（白石）と白のアゲハマ（黒石）の 2 つのトレイに、アゲハマを 1 個ずつ石として並べて表示する。
  - 対局中に取ったアゲハマは、開始時からトレイに並べておく。死に石をトレイに移すと、そのトレイに並ぶ。
  - トレイの大きさは固定（10 列 × 3 行 = 30 個分）。アゲハマの増減で画面の配置がずれて操作を誤らないようにするため。
  - 30 個を超えた分は並べず、最後の石に「+N」（さらに N 個）と重ねて書く。トレイがいっぱいのとき、石を持っていればトレイのどこをクリックしても入れられる。
- ゲーム画面の下にシードを表示し、「コピー」ボタンでクリップボードにコピーできる（文字の選択もできる）。
  - トレイの石も盤上の石と同じように持てる（クリック・範囲選択・持っている石への追加）。
  - アゲハマの個数は数字では表示しない（目数、特にマイナスの目安になるため）。
- **持つ**
  - 石をクリック（タップ）すると、その石を持つ。
  - ドラッグすると矩形範囲で選択し、範囲内の石（黒白とも）を持つ。ドラッグは空点からでも石の上からでも始められる。
  - 石を持っている間に別の石をクリック（または範囲選択）すると、持っている石に追加する。
    - 追加した石は持った順番の最後に並ぶ。
    - 盤上の石とトレイの石は混ぜて持てる。
  - 一度に持てる石の数には上限がある（設定、初期値 10 個、1〜99 個）。
    - 範囲選択で上限を超えるときは、起点（ドラッグを始めた点）に近い石から順に上限まで持ち、残りは盤に残す。トレイからも上限まで。
    - 上限まで持っているときに持とうとすると、その旨を表示して何もしない。
    - vs CPU（と対人戦）では黒・白それぞれに設定できる。CPU にも適用し、CPU は強さに応じた数（§3.1.1）とこの上限の少ない方まで持つ。
    - 途中まで置いた後でも追加できる。
  - トレイの石を盤上へドラッグすると、その 1 個を持って離した点に置く。
- **置く**
  - 空いている場所をクリックすると、持っている石を 1 個置く。残りは持ったままにする。
  - 石を持っているときに空点を押したまま動かす（なぞる・スワイプ）と、押した点となぞった空点に 1 個ずつ続けて置く。
    - 石のある点は飛ばす。速く動かして飛ばした点も、線上の点として置く。
    - 持っている石がなくなったら止まる。残りがある状態でトレイの上で離すと、残りをトレイに入れる。
    - 押した点から動かさずに離したときは、その点に 1 個置く（クリックと同じ）。
  - 置く色の選び方（白黒の入れ替えをしやすくするため）
    - 左クリック（タップ）は「置く石」で選んだ色（初期値は黒）、右クリックはその反対の色を置く。
    - 「置く石」はパネルで切り替えられる。右クリックのない端末ではこれで色を選ぶ。
    - 選んだ色の石を持っていなければ、持っている石を置く。
  - 置く石の選び方（同じ色が複数あるとき）
    - その点から持ち上げた石があれば、その石を置く（元の位置に戻すのと同じ）。
    - なければ、持った順番で最初の石を置く。範囲選択では、起点（ドラッグを始めた点）に近い順に持ったものとする（距離が同じなら上の行から左→右）。
  - ペナルティの判定（§2.5）は、持っている石をすべて置き終えて手が空になった時点で行う。
- **トレイに入れる**
  - 石を持っているときにトレイの空いた所（死に石取りの間はトレイのどこでも）をクリックするか、トレイにドロップする。
  - 持っている石のうち、そのトレイに入る色の石だけが入る。黒のアゲハマには白石、白のアゲハマには黒石が入る。
  - 盤に置くときと同じく、1 回の操作で 1 個ずつ入れる（持った順）。
  - 整地の段階では、各トレイに入れられるのはアゲハマの総数（対局中に取った石 + 死に石取りで取った石）まで。盤上の生きた石をアゲハマにはできない。
- **取り消し**
  - Esc キーで、持っている石をすべてそれぞれの元の場所（盤上の点・トレイ）に戻す。
  - 元の位置をクリックすると、その点から持ち上げた石だけが戻る（上の「置く石の選び方」）。
- 右クリックは置く色の選択に使うので、盤とトレイの上ではブラウザのメニューを出さない。
- 石を持っている間は、カーソルの横に黒と白それぞれの個数を表示する（例: ●×2 ○×3）。

### 2.5 ペナルティ

- 石を置いて手が空になった時点で、黒または白の目数（§1）が開始時と変わっていたら +5 秒を加算する。
  - モード（ひとりで・対戦）を問わず同じ。
  - 操作は止めずに、そのまま続けられる。
- 境界の石も動かせる。境界が開いている間は判定を保留する。
  - 境界が開いているとは、どちらの地でもない空点が開始時（セキの分）より多い状態をいう。
  - 境界が閉じた時点で目数を比べ、開始時と同じならペナルティにしない。
  - 例: 白の壁の石を白地の中に動かし（境界が開く）、空いた所を黒が取った白石で塞ぐ → 白地 −1、アゲハマ −1 で目数は同じなので OK。
- 目数と境界の判定では、プレイヤーが持っている石は持ち出した場所（盤の点かトレイ）にあるとみなす。対戦では相手が石を持っている最中にも自分の判定が行われるため、相手の手の中の石で目数が一時的に変わって見えても、自分のペナルティにしない（完了判定も同じ）。
- 境界が開いていても、アゲハマを相手の地に置いた場合はその場でペナルティにする。
  - アゲハマ（トレイから持った石）を、その石と反対の色の地（最後に境界が閉じていた時点）に置いたら即ペナルティ。
  - 例: 黒が取った白石を黒地に置いた。
  - 間違いの印が付いた石を動かした場合も同じ扱いにする。
- 盤上の石の移動（境界線をずらすなど）は点ごとには判定しない。境界が閉じた時点で、黒白それぞれの地の総数（目数）だけを比べる。
- 持ち上げている間は判定しない。
- ペナルティの原因になった移動を自動で元に戻すかどうかは、ゲーム設定で選べる。
  - 「元に戻す」: 戻すのは誤りの原因になった石だけ。複数の石をまとめて持って置いたときも、正しく置いた石はそのままにする。
    - アゲハマを反対の色の地に置いた誤りは、その石だけをトレイに戻す（一緒に持っていたほかの石はそのまま判定する）。
    - 境界が閉じた時点で目数が変わっていたら、まず 1 手だけ戻せば目数が戻るかを調べ、戻るならその 1 手だけを戻す。そうでなければ、境界が開く前の状態まで戻す。
  - 「そのまま」: 間違えた箇所に印（マーク）を付ける。
    - 印を付けるのは、間違いにつながった操作で置いた石と、石を持ち上げた元の点。
    - 境界が閉じた時点で目数が変わっていた場合は、境界が開く前と比べて持ち主（石の色、または地の色）が黒⇔白で入れ替わった点だけに印を付ける（例: 白の壁石を取り除いて黒石を置いた点）。そのような点がなければ、境界が開いてから動かした石と元の点すべてに印を付ける。
    - 印の付いた石を持ち上げると、その石の印は消える。印の付いた石を別の誤った場所に動かすと、印も一緒に移る。
    - 黒白の目数が開始時の値に戻ったら、すべての印を消す。
- 境界が開いている間は、画面に「境界が開いています」と表示する。

### 2.6 完了判定

目数の入力欄と「完了」ボタンは、最初から画面（パネル）に出しておく。プレイヤーは担当した地の目数を入力して「完了」を押す（Enter キーでも可）。

- 整地が完全で、入力した目数も正しければ完了。
  - 正解の目数は **開始時の目数** とする。
  - 間違えた石を残したまま（盤上の目数が開始時と違うまま）や、境界が開いたままでは、整地は完全とみなさない。
- 整地が不完全、または目数が誤っていれば +5 秒のペナルティ。続けて整地できる。
  - 失敗したら画面全体を揺らす。
  - 誤りのある場所に×を付けて表示する（次に盤かトレイを操作すると消える）。
    - 形が許可されていない区間、余りの区間が 2 つ以上あるときの余りの区間: 区間の全点
    - 境界が開いている所（両方の色に接する領域）: 接している石の少ない方の色が 3 個以下ならその石（地に混ざった別の色の石）、そうでなければ両方の色に接する空点（境界の切れ目）
  - 目数が違う入力欄は赤く強調する（入力し直すと戻る）。
  - 場所で示せない誤り（埋めていないアゲハマがある等）は、盤の上に文章で表示する。

- ひとりでモードでは、黒地と白地の目数をそれぞれ入力する。
- 目数はマイナスになることがある（アゲハマが地より多い場合）。入力欄はマイナスの値も受け付ける。
- 「最初からやり直す」ボタン（ひとりでモード）: 確認のうえ、盤・アゲハマ・段階・印を終局図の状態に戻す。タイマーとペナルティはそのまま続ける。
- 整地が完了しても画面は切り替えない。タイマーを止めて盤の操作を受け付けなくし、パネルに目数・ベストタイムと「もう一度」「設定に戻る」ボタンを出す。

### 2.6.1 ギブアップ

- ひとりでモード・vs CPU とも、「ギブアップ」ボタンで降参できる（確認あり）。
- ギブアップすると、タイムを止め、CPU が代わりに整地する（「おまかせ」カーソルで表示）。
  - 持っている石は元に戻す。ここまでの整地は、境界が閉じていて目数が変わっておらず、間違いの印もなく、CPU が続きの形を見つけられれば、そのまま引き継ぐ。
  - そうでなければ、自分が動かした石をすべて元に戻し、死に石取りからやり直す。
- CPU（vs CPU の相手とおまかせ）は、操作する場所へカーソルを動かしてから（0.25 秒後に）石を動かす。石がカーソルより先に動いて見えないようにするため。
  - vs CPU では、その時点で CPU の勝ちとする。相手の CPU は自分の整地を最後まで続ける。
- 結果の欄に正解の目数を出す。ベストタイムは記録しない。
- CPU が代わりに整地できるよう、ひとりでモードでも CPU が整地できる局面だけを作る（§3.1.1）。SGF で整地の形が見つからない場合は、その旨を表示する。

### 2.7 開始の合図

- 終局図を表示したら（初手から並べる場合は棋譜の再生が終わったら）、盤の上にカウントダウンのスピナーを出す。
- 3・2・1 と 1 秒ずつ数え、「スタート！」の合図でタイマーを動かし、操作を受け付け始める。
- 合図の前は、盤・トレイ・目数の入力を操作できない。

### 2.8 セキ

- セキの石の眼は地に数えない（日本ルール）。共有の呼吸点（両方の色に接する空点）も地ではない。
- セキの判定:
  1. 同じ色の地（その色だけに接する領域）を共有する連を、1 つのグループにまとめる。
  2. 眼が 2 つ以上あるか、7 目以上の地を持つグループは、単独で生きているとみなす。
  3. 単独で生きておらず、共有の呼吸点に接しているグループをセキの石とし、その眼を地に数えない。
- セキに接している外側の石でも、大きな地を持っていればその地は数える。
- セキには触れない: 開始時の局面で、次の点を「セキの点」とする。
  - セキの中の空点（共有の呼吸点と、セキの石の眼）
  - セキの中の空点に接する生きた石（セキの境界の石。セキのグループの石も外側の石も含む）
  - セキのグループの石でも、セキの中の空点に接していない石はセキの点ではない（触れてよい）。
- セキの点の石を持とうとしたり（クリック・範囲選択・死に石取り）、セキの中の空点に石を置こうとしたりすると +5 秒のペナルティ。石は動かさない（持てない・置けない）。範囲選択では、セキの石以外は持てる（ペナルティは 1 回）。
  - 画面を揺らし、×を付けた石を浮かび上がらせて、触れられない旨を表示する。なぞって置くときは、セキの中の点は飛ばす（ペナルティにしない）。
  - CPU とおまかせは、セキの点に触れない（動かしてよい範囲に入らない）。

### 2.9 スコアボード

- 記録はブラウザーごとに保存する（localStorage）。設定画面と結果の表示から「スコアボード」を開ける。
- ひとりで: 盤のサイズ（19 / 13 / 9）ごとのベストタイム（ペナルティ込み）上位 10 件。タイム・ペナルティの回数・日時・シード（棋譜で遊んだときは棋譜の説明）と、初期値と違う整地ルールを表示する。完了時に 10 位以内なら順位を表示する。
- vs CPU: 直近 10 戦の戦績。結果（勝ち / 負け / ギブアップ）・CPU の強さ・自分の石・盤のサイズ・双方のタイム・日時・シードを表示する。
- 各記録に「再プレイ」ボタンを置く。その記録のゲームの設定（モード・シードまたは棋譜・盤のサイズ・整地ルール・操作の設定など）を復元して、同じ終局図で始める。復元した設定は次回の設定画面の初期値にもなる。

### 2.10 シェア

- スコアボードの各記録にも「シェア」ボタンを置く。
- 本文の例:

  - vs CPU: 「vs CPU（つよい・13 路）に勝ちました！ あなた 12.9 秒・CPU 未完了（シード 20261007）」

## 3. ゲームモード

| フェーズ | モード | 内容 |
| --- | --- | --- |
| Phase 1 | ひとりで | 黒白両方の地を自分で整地し、タイムスコア（ペナルティ込み）を競う |
| Phase 2 | vs CPU | 難易度は CPU の操作間隔で設定する（§3.1.1） |
| Phase 3 | vs 人 | オンライン対戦。1 つの盤面を 2 人で同時に操作する。通信方式は後で決める |

### 3.1 対戦での担当

- 開始時に自分の石の色を選ぶ。
- 相手の地を整地する。
  - 白を選ぶ → 黒地を整地する。
  - 黒を選ぶ → 白地を整地する。

- 担当外の石への操作を許すかどうかは、ゲーム設定で選べる。
  - 制限あり: 担当の地の中の石と、自分が埋めるアゲハマだけ操作できる。死に石取りのフェーズでは、自分の地の中にある相手の死に石も操作できる。
  - 制限なし: すべての石を操作できる（妨害を含めた駆け引きになる）。

### 3.1.1 vs CPU（Phase 2）

- 設定で「モード: vs CPU」を選ぶ。自分の石の色、CPU の強さ、担当外の石の操作（制限あり／なし）を選べる。
- 1 つの盤面を人と CPU が同時に操作する。人は相手（CPU）の地を、CPU は人の地を整地する。
  - 自分が白のときは盤を 180° 回して表示する（§4）。
  - アゲハマトレイは各自のものだけ使える（相手のトレイは見えるが操作できない）。
  - 目数の入力欄は担当の地の分だけ出す。
- 担当外の石の操作を「制限あり」にすると、人は次の操作しかできない。
  - 持てるのは、相手の色の石（担当の地の石と、自分の地の中の相手の死に石）と、相手の生きた石（または担当の地）に接している自分の色の石（黒白の境界線の石）。境界線を組み直すには両方の色の石が要るため。
  - 自分の地の側の自分の石（例: 自分の石の塊の中央）は持てない。抜いて地を増やすような、担当外の操作を防ぐ。
  - 置けるのは、自分の地（相手が整地する地）以外の点だけ。
- CPU の動き（`src/game/cpu.ts`）
  - 死に石取り: 自分の地の中の相手の死に石を 1 手に 1 個ずつ取る。
  - 整地: 担当の地を、あらかじめ探した完成形（`src/game/layout.ts`）に向けて、1 手に 1 個ずつ石を動かす。石が足りなければアゲハマを埋める。
    - 境界の石は動かさないので、境界を開いたり目数を変えたりしない。
    - 担当の地に死に石が残っている間（人が取り上げる前）は待つ。
    - 盤面が計画と食い違ったら（人が担当外の石を動かしたなど）、計画を立て直す。
  - 形が整い、境界が閉じていて目数も正しければ「完了」する。
  - 強さは 5 段階。1 回の操作の間隔と、整地ミス・無駄な操作の起こりやすさで決める（`CPU_LEVELS`）。

    | 強さ | 間隔 | 整地ミス | 無駄な操作 | 一度に持つ石 | 近い順に動かす |
    |---|---|---|---|---|---|
    | 入門 | 3.0 秒 | 10% | 25% | 1 個 | しない |
    | やさしい | 2.2 秒 | 5% | 15% | 1 個 | しない |
    | ふつう | 1.5 秒 | 2% | 8% | 2 個まで | する |
    | つよい | 1.0 秒 | 0.5% | 3% | 4 個まで | する |
    | 達人 | 0.6 秒 | なし | なし | 6 個まで | する |

  - 一度に複数持つ: 盤上では、動かす石だけを含む（ほかの石を含まない）矩形を範囲選択したように、まとめて持つ。トレイからは、埋める点の数までまとめて持つ。置くのは 1 回の操作で 1 個ずつ。
  - 近い順に動かす: 死に石を取る順、持ち上げる石、置く点を、直前に操作した点から近い順に選ぶ（カーソルの移動が少ない）。

  - 整地ミス（ペナルティになる操作。人と同じく +5 秒）:
    - 死に石取りで、地に接している死に石でない相手の石を取ってしまう（死に石を 1 個取るごとに上の確率）。設定によらず元に戻る。
    - アゲハマを、反対の色の地（担当でない方の地）に置いてしまう（アゲハマを持つごとに上の確率。複数持っているときは最後の 1 個）。「そのまま」の設定では、自分が置いて印の付いた石を CPU が自分で拾い直して、担当の地に埋める（埋める所がなければトレイに戻す）。
    - 目数を数え間違えて完了する（完了するごとに上の確率の 4 倍、最大 50%。±1 目または ±10 目ずれる）。
    - 整地の途中で完了してしまう（1 回の操作ごとに上の確率の 1/3）。
  - 無駄な操作（1 回の操作ごとに上の確率）: 担当の地の石を持ち上げて、そのまま元に戻すか、地の中の別の空点に置く。目数は変わらないが、形が崩れる分だけ整地が遅れる。
  - ミスや無駄な操作を決める乱数は、終局図のシードとは別に、ゲームごとにランダムに決める（設定できない）。
  - ギブアップ時のおまかせ（§2.6.1）はミスも無駄な操作もしない。
  - CPU のカーソルを盤上に常に表示し、操作する点へ動かす（持っている石も表示する）。
- 完成形の探索: 担当の地の点と、境界に接していない内側の石を「動かしてよい範囲」とする。そこに 10 の倍数の矩形と余りの区間（矩形・しっぽ付き）を、区間どうしが辺で接しないように並べ、合計がちょうど「今の空点 − アゲハマ」になる配置を深さ優先探索で探す。
  - 細い筋や小さな飛び地ばかりの地は、境界を動かさない限り完成形が見つからない。そのため vs CPU では、終局図を作るときに黒地・白地とも完成形が見つかる局面だけを採用する（9 路はほぼすべて、13 路は約 9 割、19 路は約 3 分の 2 が採用される）。
  - SGF の棋譜で完成形が見つからない場合は、vs CPU では遊べない旨を表示する。
- 勝敗: ペナルティ込みのタイムが短い方の勝ち。両方が完了したとき、または先に完了した側のタイムを、もう一方の経過時間が超えた時点で決まる。
- 誤りの判定は盤全体で行う。境界を閉じて目数が変わったときは、目数を変えたプレイヤーのペナルティとする。
  - 判定: 境界が開いてから相手が動かした石を（仮に）元に戻した盤で、境界が閉じていて目数が変わっていれば、そのプレイヤーの操作だけで目数が変わったとみなす。
  - それで決まらなければ、持ち主が変わった点に触れたプレイヤー、それもいなければ境界を閉じたプレイヤーとする。「元に戻す」設定では、そのプレイヤー自身が動かした石だけを元に戻す（相手の操作には触れない）。

### 3.2 フェーズ

各プレイヤーは次の 2 つのフェーズを順に進める。ひとりでモードも同じ。

1. **死に石取り**
   - 自分の地の中にある相手の死に石をすべて取り上げ、自分のアゲハマトレイに移す。
   - ひとりでモードでは、盤上のすべての死に石を取り上げる。
   - 盤上の石をクリックすると、その石をそのまま取った側のアゲハマトレイに移す（黒石は白のトレイ、白石は黒のトレイ）。範囲選択で持った石は、トレイをクリックして入れる。
   - このフェーズでできるのは、盤上の石をトレイに移す操作だけ。盤上に置こうとすると、石を元の位置に戻して案内を表示する。
   - 段階の表示に、残りの死に石の数を出す。
   - 死に石でない石を取り上げるとペナルティになる。その石は設定によらず元に戻す（一緒に取った死に石はトレイに入れたまま）。
     - 目数ではなく、その石が死に石かどうかで判定する。自分の地の中の生きた石を取ると、地が 1 増えてアゲハマも 1 増えるので、目数では見分けられないため。
   - このとき、画面全体を揺らし、その石に×を付けて浮かび上がらせて消す演出を出す。
2. **整地**
   - 相手の死に石をすべて取り上げた時点で、自動的にこのフェーズに移る。
   - 取り上げた死に石と、対局中に取った石を、担当の地（相手の地）に埋めて形を整える。

死に石を取り上げるのは自分の地の中で、アゲハマを埋めるのは担当の地なので、相手の進み具合を待つ必要はない。

## 4. 盤の向き

囲碁の一般的な慣例に従い、黒の初手は黒から見て右上に打つ。

- 自分が黒: 自分（黒）の初手が右上に見えるように表示する。
- 自分が白: 相手（黒）の初手が左下に見えるように表示する（盤を 180° 回転）。
- ひとりでモード: 黒視点（初手が右上）で表示する。

## 5. 終局図の生成

- KataGo のネットワーク `kata1-b6c96-s175395328-d26788732`（g170 ラン由来、CC0）を ONNX に変換し、ブラウザ上で自動対局して局面を作る。
  - 探索はせず、方策（policy）の出力から手をサンプリングする。
  - b10c128 も試したが、19 路の生成に約 46 秒かかったため、b6c96 を採用した（19 路で約 15〜20 秒）。
  - 推論は onnxruntime-web（WASM、シングルスレッド）を Web Worker で動かす。GitHub Pages ではマルチスレッドに必要なヘッダーを付けられないため。
  - 設定画面を開いた時点で裏で 1 局作り始め、遊んでいる間に次の 1 局を作っておく。
- 対局のルールは日本ルール相当とし、ネットワークにもそのように伝える。具体的には、地で数える、セキの地は数えない、単純なコウ、コミ 6.5 目。
- 入力特徴量
  - 地で数えるルールでは、KataGo 本体と同じく「黒の着手数 − 白の着手数」をコミに足してネットワークに渡す。ネットワークはアゲハマの数を見られないため、KataGo はこの補正で「地 + アゲハマ」を表している。
- 手の選び方（本局）
  - 序盤（盤の点数の 1 割まで）は温度 1.0・top-p 0.95、以降は温度 0.5・top-p 0.8 でサンプリングする。
  - 自分の眼を埋める手は打たない。
  - 自分の確定地（所有権 0.9 以上）に打つ手は、方策が 0.3 を超えない限り打たない。
  - 方策でパスが最善になったらパスする。連続 2 回のパスで本局を終える。
  - 長すぎる対局（盤の点数の 1.3 倍の手数を超えたもの）は作り直す。
  - コウは通常のコウ（取られた直後の取り返しの禁止）だけを扱う。同一局面の反復（三コウなど）は禁止せず、繰り返しに入った対局は上の手数の上限で打ち切って作り直す。
- 目数差の調整（20 目以内が目標、厳密な制限ではない）
  - 毎手、KataGo のリード（score lead）を見る。
  - リードが 15 目を超えたら、方策の上位 4 手をそれぞれ 1 手先まで評価する。
    - 負けている側は、形勢が最も良くなる手を選ぶ。
    - 勝っている側は、リードが 10 目に最も近づく手を選ぶ。
- 後始末（ダメ埋めと手入れ）
  - 日本ルールではダメや手入れの価値が 0 なので、KataGo は打たずにパスする。そのままだと当たりの石や手入れの必要な形が残る。
  - そこで本局の後、石と地で数えるルールでネットワークに評価させ、ダメ埋めと手入れを打たせる。連続 2 回のパスまで続ける。
  - そのルールでは自分の地に打っても損がないため、打てる場所を次に限る。
    - どちらの地とも言えない点（所有権の絶対値 0.6 未満）
    - 呼吸点が 2 以下の連に接する自分の地の点（手入れ）
  - 候補手の方策が 0.05 未満ならパスする。
- 終局後の処理
  - 死に石: 連ごとに KataGo の所有権（ownership）を平均し、相手側に 0.3 以上傾いた連を死に石とする。0 付近の連はセキの可能性があるので生きとみなす。
  - ダメ: 後始末で残った両方の色に接する空点を、所有権の符号の色で埋める。石が当たりになったり石を取ったりする場合は、もう一方の色で埋める。どちらでも埋められない空点はセキとして残す。
  - 対象外とする対局（作り直す）:
    - セキとして残った空点が 4 点を超えるもの
    - 地の判定が KataGo の所有権と食い違うもの（地の平均所有権が 0.5 未満）
    - 生きた石が当たりのまま残っているもの
    - こちらで数えた日本ルールの結果と、KataGo のリードの差が max(3 目, リードの 15%) を超えるもの
  - 盤の向き: 黒の初手が右上に来るように、盤を回転・反転する（§4）。
- 投了はないので、結果は必ず B+x.5 / W+x.5 になる。
- 対局の結果（B+x.5 / W+x.5）は内部でのみ使い、画面には表示しない。

### 5.0 SGF の読み込み

- 設定の「終局図」で「SGF を読み込む」を選ぶと、終局済みの実戦の棋譜（SGF）で遊べる。
  - 本譜（各分岐の最初の手順）と初期配置（AB / AW、置き石など）を読む。盤は 2〜19 路。
  - 置き碁: AB の置き石を初期配置として置き、その後の着手は SGF に書かれた色で打つ（白から始まってよい）。KataGo の入力では、置き石も着手と同じようにコミの補正に数える（KataGo 本体と同じ）。
  - パス（`B[]`、`W[tt]`）の後に着手が続いても、そのまま再生する。
  - 手順の途中の AB / AW（局面の書き換え）には対応しない。
  - 盤のサイズは棋譜で決まる。シードは使わない。
- 死に石は KataGo の所有権で判定する（§5 の終局後の処理と同じ）。
- 終局図はダメを詰めてあることを求める。死に石を除いて両方の色に接する空点のうち、石を置いても当たりにも取り合いにもならない点（ダメ）が残っていたらエラーにして、読み込まない。置くと当たりになる点はセキの共有の呼吸点なので、エラーにしない。
  - エラーの画面には、終局図の盤を出してダメの位置に × を付ける（何か所かも表示する）。
  - エラーの画面に「このダメを埋めて始める」を置く。押すと、アプリがダメを黒か白の石で埋めて（自動で作る終局図と同じ埋め方。埋めた石は棋譜の再生の後に置く）始める。この選択はスコアボードの再プレイ用に記録に残すが、次回の設定としては保存しない。
- 実戦の棋譜は作り直せないので、§5 の「対象外とする対局」の判定に引っかかってもそのまま使う。盤の向きも変えない。
- 棋譜の結果（RE）は答えになるので画面には出さない。
- セキの確認用に、サンプルの棋譜 `public/samples/seki-9x9.sgf` を用意した。

### 5.1 開始時の表示（ゲーム設定）

- 終局図から開始する。
- 初手から棋譜を並べて開始する。1 局の再生時間は 10 秒。
  - 再生中もアゲハマトレイを表示し、石が取られるたびにリアルタイムで更新する。

- 盤サイズ: 19 路、13 路、9 路（すべて Phase 1 に含める）
- PC を優先する。
- スマートフォンでは 9 路と 13 路のみ使える。

## 7. ゲーム設定項目

設定はシード以外をブラウザーに保存し（項目を変えた時点で保存する）、次に開いたときも前回と同じ設定にする。シードは開くたびにランダムに決める。SGF の読み込みは保存しない（「自動で作る」に戻る）。

設定画面では、項目をまとまりごとに 1 つの枠で囲み、見出しを付けて並べる（項目ごとの枠は付けない）。各項目はラジオボタンで選ぶ（シードと持てる石の数は入力欄）。項目名の「?」にマウスを乗せる（フォーカスする）と、枠の右に説明の吹き出しを出す（狭い画面では下に出す）。

| 対戦 | CPU の強さ（vs CPU） | 入門 / やさしい / ふつう / つよい / 達人 |

| 整地ルール | 1 列の区間 | 制限なし / 10 目以上は禁止 / 5 目以上は禁止（§2.1.1） |
| 整地ルール | 5 × 奇数 | 認めない / 認める（§2.1.1） |
| 操作 | 一度に持てる石 | 1〜99 個（初期値 10）。vs CPU・対戦では黒・白それぞれ |
| 操作 | 担当外の石の操作（vs CPU） | 制限あり / 制限なし |
| 操作 | ペナルティ時の石 | 元に戻す / そのまま |
| 自分の色（対戦） | 黒（白地を整地） / 白（黒地を整地） |
| 担当外の石の操作（対戦） | 制限あり / 制限なし |
| CPU 難易度（Phase 2） | CPU の操作間隔 |

## 8. 技術構成

- Vite + TypeScript で静的サイトとしてビルドし、GitHub Pages で公開する（`main` への push で GitHub Actions がデプロイ）。
