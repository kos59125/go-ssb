# 囲碁スピード整地バトル 仕様書（ドラフト）

囲碁の整地を素早く完了させた方が勝ち、というゲームの HTML アプリケーション。

- 状態: ドラフト（未確定事項は「**未確定**」と記載）
- UI 言語: 日本語のみ
- 公開先: GitHub Pages（静的サイト）

---

## 1. 用語

| 用語 | 意味 |
| --- | --- |
| 地 | ある色の石（と盤端）だけで囲まれた空点の連結領域 |
| 区間 | 整地後の地を構成する、石で区切られた個々の空点領域 |
| 死に石 | 終局時点で取られる運命にある石。整地中にアゲハマとして取り上げる |
| アゲハマ | 対局中に取った石と死に石。盤外のトレイに置かれ、相手の地に埋める |
| 目数（スコア） | 地の空点数 − 相手に取られた自分の石（アゲハマ）の数（日本ルール） |

## 2. 整地ルール

### 2.1 完成形の条件

ある色の地について、次をすべて満たすとき「整地完了」とする。

1. 各区間は、同じ色の石と盤端だけで囲まれている（境界は同色）。
2. 各区間は「10 の倍数の区間」か「余りの区間」のいずれかである。
3. 「余りの区間」は、その色の地全体で **最大 1 つ**。
   - 例: 35 目 → 10+20+5、10+10+10+5、30+5 など
4. ダメはすべて埋まっている（自動で埋める。§4 参照）。
5. 盤上に死に石が残っておらず、アゲハマはすべて相手の地に埋められている。

### 2.2 10 の倍数の区間

外枠の矩形 W×H から、内側に置いた自分の石を引いた形。

- 内側の石は **区間の中心に対して点対称** に置く。
- 点対称でない配置（例: 4x4−6）は不可。

```
xxxxx
x...x
x.x.x
x.x.x
x...x
xxxxx
```
10 目（3x4−2）

```
+------------
|..........x
|..........x
|xxxxxxxxxxx
|
```
20 目（10x2）

```
xxxxxxxxx
x.......x
x...x...x
x.......x
xxxxxxxxx
```
20 目（7x3−1）

**未確定**: 内側の石の形の制約（§7 Q1）

### 2.3 余りの区間

- 他の区間と独立して配置する。
- 偶数目: 矩形（例: 6 = 2x3、8 = 2x4）
- 奇数目: 矩形、または矩形に「しっぽ」1 マスが付いた形（例: 5 = 2x2+1、7 = 2x3+1）

**未確定**: しっぽの位置（§7 Q2）

### 2.4 石の操作

- 盤上の石は、自分の色・相手の色を問わず動かせる。新しい石は使わない。
- **持つ**
  - 石をクリック（タップ）すると、その石を持つ。
  - 石の上からドラッグすると、その石を持ったまま移動し、ドロップで置く。
  - 空点からドラッグすると、矩形範囲で選択し、範囲内の複数の石を持つ。
- **置く**
  - 空いている場所を再タップするか、ドロップすると、持っている石を置く。
- **取り消し**
  - 元の位置（範囲）を再タップすると、持つのをやめる。
- **アゲハマ**
  - 死に石も移動の対象。死に石を盤外のアゲハマトレイに移すと「取り上げ」になる。
  - 対局中に取ったアゲハマは、開始時から盤外トレイに適当に配置しておき、移動の対象にする。

**未確定**: 複数の石を置くときの挙動（§7 Q6）

### 2.5 ペナルティ

石を置いた時点で目数（§1）が開始時と変わった場合、その時点で時間ペナルティを科す。

- 例: 黒のアゲハマを白の地に置いた → 白の目数が変わる → ペナルティ
- 持ち上げている間（境界が一時的に開いている間）は判定しない。

**未確定**: 秒数、対戦時の扱い（§7 Q5）

### 2.6 完了判定

「完了」ボタンを押すと、プレイヤーは整地した地の目数を入力する。

- 整地が完全で、入力した目数も正しければ完了。
- 整地が不完全、または目数が誤っていればペナルティ。

**未確定**: 入力する目数の対象（§7 Q4）

## 3. ゲームモード

| フェーズ | モード | 内容 |
| --- | --- | --- |
| Phase 1 | ひとりで | 黒白両方を自分で整地し、タイムスコアを競う |
| Phase 2 | vs CPU | 難易度は CPU の操作間隔で設定する |
| Phase 3 | vs 人 | オンライン対戦。1 つの盤面を 2 人で同時に操作する |

- 対戦では、黒か白のどちらかが自分に割り当てられる。
- ゲーム開始時に、どちらの地を整地するかを決める。

## 4. 終局図の生成

- KataGo のネットワークを使い、ブラウザ上で終局まで自動対局して局面を生成する。
  - ネットワークは初回にロードする。
  - 投了で終わらず、B+x.x / W+x.x で終わる対局のみを対象にする。
- 開始時に全局の棋譜を高速で再生し、終局図から整地を始める。地の場所が分かりやすくするため。
- 死に石は KataGo の ownership で判定する。
- ダメは自動で埋める。ダメを埋めきれない局面は対象外にする。
- セキを含む局面も対象にする。

## 5. 盤サイズと対応端末

- 盤サイズ: 19 路、13 路、9 路（すべて Phase 1 に含める）
- PC を優先する。
- スマートフォンでは 9 路と 13 路のみ使える。

## 6. 技術構成（案）

- Vite + TypeScript で静的サイトとしてビルドし、GitHub Pages で公開する。
- 推論には onnxruntime-web（WebGPU / WASM）を使う。
- 整地判定ロジックは UI から分離し、単体テストを書く。
