# 囲碁スピード整地バトル ルールブック

## ゲームの目的

囲碁の終局図を、日本式の整地の形にできるだけ早く整えます。ペナルティを含めたタイムが短い方が勝ちです。

## vs CPU

- あなたと CPU が同じ盤を同時に整地します。あなたは CPU の地を、CPU はあなたの地を整地します。
- まず自分の地の中にある相手の死に石を取り上げ、それから相手の地にアゲハマを埋めて形を整えます。
- ペナルティ込みのタイムが短い方の勝ちです。
- 設定で「担当外の石の操作: 制限あり」にすると、相手の色の石と、相手の石に接している自分の色の石（境界線の石）しか動かせず、自分の地には石を置けません。自分の地の側の石（自分の石の塊の中央など）は動かせません。
- 盤上の「CPU」と書かれたカーソルが、CPU の操作している場所です。
- CPU の強さは 5 段階（入門・やさしい・ふつう・つよい・達人）です。弱い CPU ほど操作がゆっくりで、整地ミス（ペナルティ）や無駄な石の移動が多くなります。

## 整地の手順

1. **死に石を取り上げる**
   自分の地の中にある相手の死に石を、すべてアゲハマトレイに移します。死に石をクリックすると、そのままアゲハマトレイに入ります。全部取り上げると、自動で次の手順に進みます。
2. **アゲハマを埋める**
   アゲハマを相手の地に置きます。地の空きよりアゲハマが多いときは、地を全部埋めます。残りはトレイに置いたままで、目数はマイナスになります。
3. **地の形を整える**
   地を「10 の倍数の区間」と「余りの区間」に分けます。
4. **完了を宣言する**
   画面右の入力欄に整地した地の目数を入力して、「完了」ボタンを押します。

対戦では、囲碁の慣例どおり **相手の地を整地** します。

## 区間のルール

- 各区間は、その地の色の石（と盤の端）だけで囲みます。
- 区間どうしは石で区切ります。ただし、区間の角どうしが斜めに接するのは構いません。
- 「余りの区間」は、その色の地全体で 1 つまでです。
  - 例: 35 目なら 10+20+5、10+10+10+5、30+5 など

### 10 の倍数の区間で使える形

- **矩形**: 10x1、5x2、10x2、5x4、10x3 など
- **3x4−2（10 目）**: 中央に 2 個の石を置く
- **7x3−1（20 目）**: 中央に 1 個の石を置く
- **7x6−2（40 目）**: 中央に 2 個の石を置く

```
xxxxx      xxxxxxxxx      xxxxxxxxx
x...x      x.......x      x.......x
x.x.x      x...x...x      x.......x
x.x.x      x.......x      x...x...x
x...x      xxxxxxxxx      x...x...x
xxxxx                     x.......x
                          x.......x
 10 目        20 目        xxxxxxxxx
                             40 目
```

### 使えない形

- **しっぽ付きの形**: 6x8+2、7x7+1 のように、矩形に石や空点の「しっぽ」を付けて 10 の倍数にする形は使えません。
  実際の整地では見かける形ですが、このゲームでは **不可** です。
- **上の一覧にない形**: 4x4−6、5x5−5（十字）など、上の一覧にない内側の石の置き方も使えません。

### 余りの区間で使える形

余りの区間は 1〜9 目で、次の形を使えます。

- 矩形（1x3、2x3 など）
- 奇数目のときに限り、矩形の辺に 1 マスの「しっぽ」を付けた形（2x2+1、2x3+1 など）

## 操作方法

| 操作 | 方法 |
| --- | --- |
| 石を持つ | 石をクリック（タップ） |
| 複数の石を持つ | ドラッグして範囲を選ぶ（空いているところからでも石の上からでも） |
| 持っている石に追加する | 石を持ったまま、別の石をクリック（または範囲選択） |
| 石を置く | 空いているところをクリックすると 1 個置きます。残りは持ったままです |
| 置く色を選ぶ | 左クリックは黒、右クリックは白を置きます（パネルの「置く石」で左右を入れ替えられます） |
| 続けて置く | 石を持ったまま、空いているところを押してなぞる（スワイプ）と、なぞった所に 1 個ずつ置きます |
| 持つのをやめる | Esc キーで全部元に戻ります。元の位置をクリックすると、その石だけ戻ります |

### アゲハマトレイ

- アゲハマは盤の横のトレイに石として並んでいます。盤上の石と同じように、クリックや範囲選択で持てます。
- トレイの石を盤へドラッグすると、そのまま置けます。
- 死に石を取り上げるときは、死に石をクリックするだけでトレイに入ります。

白と黒の境界を入れ替えたいときは、入れ替える黒石と白石を両方持ち、黒石があった点を右クリック（白を置く）、白石があった点を左クリック（黒を置く）します。

### やり直し

ひとりでモードでは「最初からやり直す」ボタンで終局図の状態に戻せます。タイマーとペナルティはそのまま続きます。

### ギブアップ

「ギブアップ」ボタンで降参すると、CPU が代わりに整地して正解を見せてくれます。vs CPU では CPU の勝ちになります。

## ペナルティ（+5 秒）

次の場合にタイムに 5 秒が加算されます。操作はそのまま続けられます。

- 石を置いたときに、黒または白の目数が変わってしまった場合
  - 例: 相手の地に入れるべきアゲハマを自分の地に置いた
  - 境界の石を動かして境界が開いている間は判定を待ちます。境界を閉じた時点で目数が変わっていなければペナルティになりません。
- 「完了」を押したときに、整地が完全でないか、入力した目数が違っていた場合

ペナルティの原因になった石を自動で元に戻すかどうかは、設定で選べます。元に戻さない設定では、間違えた石と、石を持ち上げた元の場所に印が付きます。正しく直すと印は消えます。間違いが残っている間は「完了」できません。
